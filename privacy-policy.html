01

Information We Collect

Registration & Account Information

  • Agency/Vendor name
  • Contact person name
  • Mobile number
  • Agency/vendor type (Outside Agency, Chef Labour, Labour/Labour Agency, RM Agency, etc.)
  • Address (optional)
  • Email address (if provided)
  • OTP verification records (for mobile number verification during registration and login)

Order & Business Information

  • Order details assigned by caterers (order number, event date, client name, function details, assigned requirement, menu/quantity details)
  • Order responses (Accept/Reject status, remarks/comments)
  • Order status history, including cancellations and reassignments
  • Response date and time

Device Information

  • Device model and operating system version
  • Device identifiers
  • IP address
  • Push notification token (used to deliver order and status notifications)

Usage Information

  • Login activity
  • App usage data
  • Error logs and diagnostic information
02

How We Use Your Information

We use collected information to:

  • Register and verify Vendors via OTP, and confirm that a mobile number is linked to an authorized caterer before activating an account
  • Authenticate users and manage secure sessions
  • Display assigned orders, order details, and order status in the Vendor dashboard
  • Send push notifications when an order is assigned, updated, cancelled, or reassigned
  • Capture and transmit Accept/Reject decisions and remarks back to the caterer
  • Keep order status synchronized in real time between the App and the JUCAS Web App
  • Improve user experience and app performance
  • Respond to support requests
  • Monitor security and prevent unauthorized access, duplicate registrations, or fraudulent account activation
  • Comply with legal obligations
03

Information Sharing

We do not sell, rent, or trade personal information. Because the App is an integrated extension of the JUCAS Web App, certain information is necessarily shared as part of the order-coordination workflow, including:

  • Order details and status updates shared with the caterer/administrator who created and assigned the order via the JUCAS Web App
  • Vendor registration and contact details shared with authorized caterers to enable order assignment
  • Accept/Reject responses, remarks, and timestamps shared with the caterer through the JUCAS Web App

Beyond this core workflow, we may share information only:

  • When required by law or legal process
  • To protect the rights, safety, and security of users and the Company
  • With trusted service providers who help operate the App (e.g., hosting, SMS/OTP delivery, push notification providers)
No data sold to advertisers Shared only within the order workflow
04

Integration with the JUCAS Web Application

The App is designed to work together with the JUCAS Web App. When a caterer creates an order and sends an order confirmation to a Vendor, order details are transmitted to the App and a push notification is sent to the assigned Vendor. When a Vendor accepts, rejects, or receives a cancelled/reassigned order, that response, along with remarks and the response date/time, is synchronized back to the JUCAS Web App so the order status stays consistent across both platforms.

This synchronization is core to the App and cannot be disabled while using order-related features.
05

Data Security

We use reasonable technical and organizational safeguards to protect your information, including restricting order and vendor data to authorized caterers and Vendors. However, no method of electronic transmission or storage is completely secure, and we cannot guarantee absolute security.

06

Data Retention

We retain personal, registration, and order information only as long as necessary to provide our services, maintain order/cancellation history, and meet legal or business requirements.
